# TodoList (vanilla JS)

A polished, modern Todo app with filtering and localStorage persistence. Built with plain HTML/CSS/JS.

## Features
- Add, edit, toggle and delete tasks
- Filters: All / Active / Completed
- Clear all completed tasks
- Persistent across reloads via localStorage
- Keyboard friendly (Enter to save edit, Esc to cancel)

## Run locally

Option 1: Use Python's simple HTTP server

```bash
cd /workspace/todolist
python3 -m http.server 5173
```
Visit http://localhost:5173 in your browser.

Option 2: Use any static server.
